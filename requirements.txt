# AirControl V1 dependencies
#
# NOTE on mediapipe version: pinned to 0.10.14. Newer mediapipe releases
# (0.10.18+) removed the legacy `mp.solutions.hands` API in favor of the
# Tasks API, which requires downloading a separate .task model file at
# runtime. 0.10.14 ships its hand-tracking model inside the pip wheel, so
# AirControl works fully offline after `pip install` — no extra downloads,
# no extra config. If you intentionally want to upgrade mediapipe, see the
# "Upgrading MediaPipe" section in README.md first.
#
# NOTE on the cv2 package: do NOT add `opencv-python` here. `mediapipe`
# already pulls in `opencv-contrib-python` as a transitive dependency, and
# both packages install into the same top-level `cv2` directory — whichever
# one pip installs last silently overwrites the other's files. Declaring
# our own `opencv-python` alongside mediapipe's `opencv-contrib-python`
# doesn't give two working installs, it gives one broken/undefined one,
# and any version pin on our `opencv-python` line is not actually enforced
# (this bit us: `opencv-python<5` was declared, but `opencv-contrib-python`
# 5.x still ended up owning `cv2` after a plain `pip install -r
# requirements.txt`). AirControl doesn't use any contrib-only modules, so
# we pin the package that actually wins instead of fighting mediapipe for
# the namespace.
opencv-contrib-python>=4.9,<5
mediapipe==0.10.14
numpy>=1.26,<2.3
pyautogui>=0.9.54,<1
pynput>=1.7,<2
